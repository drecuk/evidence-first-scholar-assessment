# Report template guide

The packaged Word template is:

```text
assets/research-quality-scholarly-impact-template.docx
```

Use it when the user requests a committee-ready Word document or when local practice requires the supplied format. Copy it into the case workspace before editing; do not modify the packaged original.

Populate the template from verified evidence and generated tables. Keep the executive verdict, scope, identity assessment, selected-output review, metrics, peers, contribution, robustness/integrity, scorecard, gates, evidence gaps, and final assessment synchronized with the Markdown report and committee brief.

When document tools are available:

1. Edit the copied template rather than reconstructing its styles from scratch.
2. Preserve the existing page setup, headings, table styles, headers, and footers unless the user requests a redesign.
3. Add source notes and limitations near the relevant table or claim.
4. Render the final DOCX to page images or PDF.
5. Inspect every page and correct clipping, split rows, orphan headings, unreadable footnotes, missing glyphs, blank pages, and inconsistent page numbers.
6. Confirm that all displayed metrics match the generated CSV/JSON and that no placeholder text remains.

If reliable Word rendering is unavailable, deliver the populated DOCX with that limitation stated and retain the Markdown report as the canonical auditable version.
