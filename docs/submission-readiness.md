## Publisher-controlled steps for the universal public directory

Direct installation from this GitHub marketplace does not equal approval in OpenAI's universal public Plugins Directory. Before a directory submission, the publisher must:

1. Select and verify the intended individual or business developer identity in the submission portal.
2. Confirm the currently available category and country targeting.
3. Review the listing copy, icon, and data-practice statements under that verified identity.
4. Complete any portal attestations and policy checks.
5. Upload the exact release ZIP as a draft, inspect the imported metadata, test the installed skill, and submit it for review as a separate authorized action.

Skills-only plugins do not require MCP test cases, reviewer credentials, or an MCP demo recording. Requirements can change; recheck the official OpenAI plugin documentation before submitting.

This package intentionally does not invent a privacy policy, terms of service, legal identity, country allowlist, or approval state.
